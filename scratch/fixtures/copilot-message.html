Widget 5 was released on March 3, 2026 as the new "Current" release. The main changes include: 

Key New Features in Widget 5

  1. Render Engine 3.2

    • Upgraded to Render Engine 3.2.
    • Includes support for:
      • HalfFloatBuffer
      • Scoped Resources
      • Widget.isWidget()

  2. PathMatcher Is Now Global

    • Available without importing a module.
